# 部署指南

## 一、服务器选型

| 项目 | 最低 | 建议 | 说明 |
| --- | --- | --- | --- |
| CPU | 1 核 | 2 核 | 解析主要等浏览器，不怎么吃 CPU |
| 内存 | 1 GB | 2 GB | Chrome 无头约 300–500 MB，留余量 |
| 磁盘 | 10 GB | 20 GB | 代码 + 数据库很小，主要是系统 |
| 系统 | Ubuntu 22.04 / Debian 12 | 同左 | 也可以 Windows Server |

云厂商：腾讯云轻量 2C2G、阿里云 ECS 2C2G 都够用，包年价格一百多到两百。
**没有服务器也能先跑通**：本地电脑 + 内网穿透（cpolar / frp）先测，
但小程序正式发布必须用备案过的 HTTPS 域名。

> 不要用 1核1G 的最低配：Chrome 起不来，会一直 `解析失败`。

## 二、域名与备案（国内小程序必做）

1. 买域名 → 完成 **ICP 备案**（腾讯云/阿里云控制台可提，约 3–10 天）
2. 申请 **SSL 证书**（免费 DV 证书即可）
3. 把域名解析到服务器 IP
4. Nginx 反代到 `127.0.0.1:8000`

小程序要求 `request` / `downloadFile` 域名必须是 **HTTPS + 已备案**，且不能带端口。

## 三、安装 Chrome

解析依赖一个真实浏览器环境。

**Ubuntu / Debian**

```bash
sudo apt update
sudo apt install -y wget gnupg ca-certificates fonts-wqy-zenhei
wget -q -O - https://dl.google.com/linux/linux_signing_key.pub | sudo apt-key add -
sudo sh -c 'echo "deb [arch=amd64] http://dl.google.com/linux/chrome/deb/ stable main" > /etc/apt/sources.list.d/google.list'
sudo apt update && sudo apt install -y google-chrome-stable
google-chrome --version
```

字体包 `fonts-wqy-zenhei` 别漏，否则中文页面渲染异常，可能影响风控判定。

**CentOS / Rocky**

```bash
sudo dnf install -y https://dl.google.com/linux/direct/google-chrome-stable_current_x86_64.rpm
sudo dnf install -y wqy-zenhei-fonts
```

Chrome 找不到时，在 `config.json` 里写死：

```json
"parse": { "chrome_path": "/usr/bin/google-chrome" }
```

## 四、部署后端

```bash
# 1. 上传代码（本地执行）
scp -r douyin-tool/server root@你的IP:/opt/douyin-tool/

# 2. 服务器上
cd /opt/douyin-tool/server
python3 app.py            # 先前台跑一遍，看有没有报错
```

首次启动会自动生成 `config.json`，里面有后台密码和签名密钥，**别外传**。

### systemd 常驻

`/etc/systemd/system/douyin.service`

```ini
[Unit]
Description=Douyin watermark tool backend
After=network.target

[Service]
Type=simple
WorkingDirectory=/opt/douyin-tool/server
ExecStart=/usr/bin/python3 -u app.py
Restart=always
RestartSec=5
Environment=PYTHONUNBUFFERED=1

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now douyin
sudo systemctl status douyin
journalctl -u douyin -f          # 看日志
```

### Nginx 反代

```nginx
server {
    listen 443 ssl http2;
    server_name api.yourdomain.com;

    ssl_certificate     /etc/nginx/ssl/fullchain.pem;
    ssl_certificate_key /etc/nginx/ssl/privkey.pem;

    # 视频下载比较大，放开限制
    client_max_body_size 20m;
    proxy_read_timeout 300s;
    proxy_send_timeout 300s;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_buffering off;          # 视频流式输出，别缓存整个文件
    }
}

server {
    listen 80;
    server_name api.yourdomain.com;
    return 301 https://$host$request_uri;
}
```

配好后把公网地址写进配置，让下载直链带上域名：

```json
"server": { "public_base": "https://api.yourdomain.com" }
```

也可以直接在后台「对外域名」里填，改完即时生效。

## 五、验证

```bash
curl https://api.yourdomain.com/api/health
# {"ok": true, "browser": true, "uptime": 12}

curl -X POST https://api.yourdomain.com/api/parse \
  -H "Content-Type: application/json" \
  -d '{"url":"https://v.douyin.com/xxxx/"}'
```

`browser:false` 说明 Chrome 没起来，看 `journalctl -u douyin` 里的报错。

## 六、Docker（可选）

```bash
docker build -t douyin-tool .
docker run -d --name douyin-tool \
  -p 8000:8000 \
  -v $(pwd)/server/data:/app/data \
  -v $(pwd)/server/config.json:/app/config.json \
  --shm-size=1g \
  douyin-tool
```

`--shm-size=1g` 必须加，否则 Chrome 在容器里容易崩。

## 七、备份

需要备份的只有两样：

```bash
# 数据库（解析记录、缓存、反馈）
cp server/data/data.db backup/data-$(date +%F).db

# 配置（含后台密码、密钥、广告位）
cp server/config.json backup/config-$(date +%F).json
```

建议加一条 crontab 每天打包，顺手传到对象存储。
