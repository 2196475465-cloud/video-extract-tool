# 小程序上线与广告接入

## 一、注册小程序

1. 打开 https://mp.weixin.qq.com → 立即注册 → 小程序
2. 用邮箱注册，主体选 **个人** 或 **企业**
   - 个人主体：不需要营业执照，但部分类目和流量主权限受限（流量主个人也可以开）
   - 企业主体：需要营业执照，可开通更多能力
3. 注册完成后在「开发 → 开发管理 → 开发设置」拿到 **AppID**
4. 把这个 AppID 填到 `miniprogram/project.config.json` 的 `appid` 字段

## 二、类目选择（关键，决定能不能过审）

在「设置 → 基本设置 → 服务类目」选择：

| 建议类目 | 说明 |
| --- | --- |
| 工具 → 图片/视频处理 | 最贴合，个人主体可选 |
| 工具 → 效率 | 备选 |

**不要**选「影视」「内容资讯」这类需要资质的类目。

### 名称与简介的写法

审核对「去水印」这类词比较敏感，容易判定为「侵犯他人知识产权」或「提供违规内容」。
实操上这样写通过率更高：

- 名称：`XX提取`、`视频助手`、`短视频工具箱`
- 简介：`视频链接解析与本地保存工具，支持视频、图集、原声保存`
- 页面文案：用「提取原片」「保存到相册」，少用「破解」「去除水印」这种表述

小程序里已经用「短视频提取」做品牌词，功能描述也做了软化处理。

## 三、配置服务器域名

「开发 → 开发管理 → 开发设置 → 服务器域名」：

| 类型 | 填写 |
| --- | --- |
| request 合法域名 | `https://api.yourdomain.com` |
| downloadFile 合法域名 | `https://api.yourdomain.com` |

要求：HTTPS、已备案、不能带端口、不能是 IP。

本地调试时在开发者工具「详情 → 本地设置」勾选「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」，就能直连 `http://127.0.0.1:8000`。

## 四、改配置并上传

1. `miniprogram/config.js` 里 `baseUrl` 改成你的 HTTPS 域名
2. 开发者工具点「上传」，填版本号和备注
3. 后台「管理 → 版本管理」提交审核
4. 审核通过后点「发布」

### 审核常见驳回与应对

| 驳回理由 | 处理办法 |
| --- | --- |
| 类目与内容不符 | 换成「工具-图片/视频处理」，重新提审 |
| 涉及侵权风险 | 首页加免责声明入口（已有）、审核备注里说明「仅本地保存个人备份，不提供内容分发」 |
| 诱导分享 | 不要做「分享得次数」，目前代码里没有这类逻辑，保持 |
| 功能不完整 | 提交时填测试说明：粘一条抖音分享链接即可完整走通 |
| 广告相关 | 未开通流量主前，广告位 ID 留空，页面不会渲染广告；审核时不要出现「看广告」字样（当前文案是「看一小段短视频」） |

## 五、开通流量主

条件：小程序 **累计独立访客（UV）≥ 1000**，且无严重违规记录。

开通路径：「流量主 → 开通」，完善结算信息（个人可绑银行卡）。

开通后创建广告位：

| 广告类型 | 位置 | 建议尺寸 | 在本项目里的作用 |
| --- | --- | --- | --- |
| 激励视频 | 保存前解锁 | 自动 | 主要收入来源 |
| Banner | 首页 / 结果页底部 | 自动 | 补充收入 |
| 插屏 | 保存成功后 | 自动 | 补充收入，别太频繁 |

创建后你会拿到形如 `adunit-xxxxxxxxxxxxxxxx` 的 ID。

## 六、把广告位填进系统

两种方式，后台优先级更高、改完不用重新发版：

**方式 A：运营后台（推荐）**

打开 `https://api.yourdomain.com/admin?token=你的后台密码`，在
「广告位与次数」里填三个 ID，保存。小程序下次启动自动拉取。

**方式 B：改成默认值**

编辑 `miniprogram/config.js`：

```js
adUnits: {
  rewarded: 'adunit-xxxxxxxx',
  banner: 'adunit-xxxxxxxx',
  interstitial: 'adunit-xxxxxxxx'
}
```

## 七、次数与广告的联动逻辑

在后台可调三个参数：

- **每天免费次数**（默认 3）：每天前 N 次提取不消耗广告
- **每天看广告最多加几次**（默认 10）：防刷，单日上限
- **每次广告解锁次数**（默认 1）：看一次视频送几次

实际体验路径：

```
免费次数用完 → 点「看视频 +1 次」→ 激励视频播放完 → 本地额度 +1
保存原片时 → 若配置了激励视频广告位 → 看一次解锁本次全部下载
```

广告拉取失败时**自动放行**（不给用户卡死），这是刻意的产品取舍：
宁可少一次曝光，也不要让用户保存不了。

## 八、上线后第一天要盯什么

1. 后台「今日解析」是否有量、成功率是否 ≥ 95%
2. 「失败原因 Top」里如果大量出现同一错误，通常是抖音侧变了，看维护手册
3. 服务器内存：`free -h`，Chrome 常驻约 400 MB
4. 小程序「运维中心 → 错误日志」看有没有 JS 报错

## 九、成本与收益参考

- 服务器 2C2G：约 15 元/月
- 域名：约 30–60 元/年
- 带宽：视频走服务器反代，1 万次下载（每条 10 MB）约 100 GB 流量
  - 按量计费约 0.8 元/GB → 80 元；或直接用 5 Mbps 固定带宽（约 100 元/月）更划算
- 激励视频 eCPM 大约 20–60 元，即 1000 次完整播放约 20–60 元

收入依赖真实使用量，别指望一上线就有钱，先把解析成功率做稳。
