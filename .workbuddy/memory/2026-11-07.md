## 抖音去水印微信小程序（douyin-tool）

需求：模仿桌面工具「一键去水印」，做微信小程序；复制抖音链接→下载无水印视频；接广告；可维护。

### 关键调研结论（重要，后续会复用）
- 抖音 2026 年已堵死纯服务端解析：
  - `iesdouyin.com/web/api/v2/aweme/iteminfo/` 返回空
  - 分享页 SSR 的 `_ROUTER_DATA` 不再包含 `videoInfoRes`
  - `www.douyin.com/aweme/v1/web/aweme/detail/` 带 a_bogus 签名仍返回
    `403 Blocked by ArgusSecurityPlugin Uifid Not Found`
  - 爬虫 UA（Baiduspider/Googlebot）也拿不到数据
- 可行方案：**无头 Chrome 打开抖音视频页 → 页面内 fetch 详情接口**，SDK 自动签名，
  返回 200 与完整 `aweme_detail`（play_addr 即无水印直链）
- 性能实测：预热一次（页面 readyState=complete 且 cookie 有 UIFID）后，
  单条 0.2~0.5s；2 个标签页并发 4 条最慢 3.2s
- 复用开源项目 Evil0ctal/Douyin_TikTok_Download_API（21.2k stars，Apache-2.0）的
  `abogus.py` + `sm3.py` 作为签名备用能力，已放 `server/core/signing/` 并写 NOTICE

### 产出
`C:/Users/GLX/OneDrive/Desktop/小项目/douyin-tool/`
- `server/`：Python 标准库零依赖后端（ThreadingHTTPServer + 自实现 CDP WebSocket 客户端）
  - 接口：/api/parse、/api/dl（HMAC 签名反代）、/api/config、/api/feedback、/admin
  - SQLite：parses/cache/feedback；配置热加载 config.json
- `miniprogram/`：5 个页面（index/result/history/mine/help）+ ad-banner 组件
  - 激励视频解锁保存、Banner、插屏；每日免费额度 + 看广告加次数
- `docs/`：部署指南、小程序上线与广告接入、维护手册
- 实测：9 次解析 100% 成功，视频反代 77MB mp4 正常

### 技术要点备忘
- Chrome 路径自动探测（Win/mac/Linux），找不到读 `parse.chrome_path`
- 预热失败要重新导航；403 时置 ready_until=0 触发重预热
- 下载链接用 HMAC(secret, kind|id|index|expire) 签名，防刷
- public_base 未配置时用请求 Host 兜底，方便本地联调

### 待用户提供才能上线
AppID、备案域名 + HTTPS、服务器（2C2G 起）、流量主广告位 ID

## 界面改版（同日第二轮）

用户要求"调好看一点"，做了系统性视觉升级：

- 新增 `miniprogram/styles/icons.wxss`：21 个线性 SVG 图标 × 4 色，base64 内联，
  由 `tools/gen_icons.py` 生成。替换掉原来用 `?` `✎` `☎` `§` 当图标的做法。
- `app.wxss` 建立设计令牌：主色渐变、三级圆角、两档阴影、语义色；`@import` 图标。
- 首页：hero 加径向光晕 + 网格纹理、金色高亮标题、平台标签胶囊；
  输入区做成「粘贴槽」（虚线分隔 + 胶囊按钮）；三步改为三列图标卡；最近提取改小卡片横滑。
- 结果页：视频卡加大圆角与投影、信息卡合并标题/参数 chips/作者行、保存按钮带图标、
  次级操作改圆形图标按钮。
- 我的页：额度卡改大数字布局 + 白色 CTA 胶囊 + 进度条 + 底部统计；菜单改圆角图标块 + 细分割线。
- **修掉一个真 bug**：`.nav { height: 92rpx }` 与 `padding-top: 状态栏高度` 在
  border-box 下互相挤压，导致标题被顶到状态栏上方。改为不设固定高度、只留 padding。
- 兼容性清理：去掉 flex `gap`、`inset`、`filter: blur`（改用 radial-gradient 模拟光晕），
  避免老安卓 WebView 渲染异常。
